# 成绩录入 — 按考试场次的学生 × 科目矩阵

- 日期：2026-11-22
- 状态：已确认
- 范围：成绩录入页面（`/scores`，ADMIN / TEACHER）

## 1. 需求

每个学生在**同一次考试**中的各科成绩在同一行展示，方便横向查看与录入。

现有数据模型中考试挂在单门课程下，因此约定：

> 不同课程下**考试名称相同**的考试视为同一次考试（如三科各自的“期中考试”）。

## 2. 交互

成绩录入页顶部：

- 选择考试（按名称去重，带考试日期）
- 按班级筛选（可选）
- 刷新、保存成绩

表格：

- 固定列：学号、姓名、班级
- 动态列：本次考试聚合到的每门课程一列，列头显示课程名、考试日期与满分
- 单元格：数字输入框，范围 `0 ~ 该考试满分`

保存时把每个非空单元格展开为 `{studentId, examId, score}`，复用现有批量保存接口。

## 3. 接口

### `GET /api/exams/sessions`

返回当前用户可访问课程下的考试名称去重列表，按日期升序。

```json
[{ "name": "期中考试", "examDate": "2026-11-15" }]
```

### `GET /api/scores/session?examName=期中考试&className=软件工程2601`

返回透视后的矩阵。`className` 可选。

```json
{
  "examName": "期中考试",
  "exams": [
    { "examId": 2, "courseId": 1, "courseName": "高等数学", "examDate": "2026-11-15", "fullScore": 100 }
  ],
  "rows": [
    {
      "studentId": 1,
      "studentNo": "2026001",
      "studentName": "张伟",
      "className": "软件工程2601",
      "scores": { "2": 72 }
    }
  ]
}
```

### 保存

复用 `POST /api/scores/batch`，请求体：

```json
{ "items": [{ "studentId": 1, "examId": 2, "score": 72 }] }
```

## 4. 权限

- 管理员：可访问全部课程。
- 教师：只聚合自己所授课程的考试列（服务端过滤）。
- 学生：无权访问以上接口。

## 5. 边界

- 没有可访问考试：返回 `exams: []`、`rows: []`，前端显示空状态。
- 考试名称不存在：返回空矩阵，不报错。
- 未录入的单元格为空，保存时跳过。
- 清空输入框不会删除已有成绩（与现有批量保存行为一致）。

## 6. 测试

后端集成测试（`ExamIT` / `ScoreIT`）：

- 场次列表去重、按日期排序；
- 教师场次列表不含其他教师课程的考试；
- 矩阵包含全部课程列、每名学生一行、分数正确；
- 教师矩阵只含自己的课程；
- 班级筛选生效；
- 学生访问被拒绝；
- 不存在的考试名称返回空矩阵。

前端 Vitest：

- 批量保存数据扁平化：跳过空值、保留 0 分。
